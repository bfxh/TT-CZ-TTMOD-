# 设计规范 · 资产库界面

现行规范。原则：**做成一台干练的工具，不做展示页**。所有决定都服务于
「在三万条资产里快速找到、并正确判断一个模型」。

## 一、色彩

一套灰阶 + **单一强调色**。颜色**只出现在「点」上**（6px 类型点 / 游戏点 / 状态点），
不铺面板、不做渐变、不做毛玻璃。

| 令牌 | 浅色 | 深色 | 用途 |
|---|---|---|---|
| `--bg` | `#EFEFF1` | `#151517` | 应用底 |
| `--panel` | `#FFFFFF` | `#1D1D20` | 面板 / 卡片 |
| `--panel-2` | `#F7F7F8` | `#232327` | 次级面（表头 / 缩略图底 / 代码块） |
| `--line` | `#E2E2E5` | `#323238` | 结构分隔线 |
| `--line-2` | `#EDEDEF` | `#292930` | 组内分隔线 |
| `--text` | `#191919` | `#E9E9EB` | 主文字 |
| `--text-2` | `#5F5F66` | `#9C9CA5` | 次要文字 |
| `--text-3` | `#98989F` | `#6C6C76` | 标签 / 占位 / 数字 |
| `--accent` | `#2B62D9` | `#5B8DEF` | 选中 / 当前排序 / 主按钮 |
| `--accent-soft` | `#EAF0FD` | `#1E2A44` | 选中底 |
| `--warn` | `#B26A00` | `#D08A2A` | 重复副本 |

类型色（仅作点，不做文字或底色的唯一信息载体）：

```
模块 #3D7BE0   武器 #C0503F   机甲 #B4791F   载具 #3E8FA8   建筑 #5A5AA8
地形 #8A7355   植被 #3E8A4E   道具 #B04A66   无人机 #3E9A96 特效 #A08A20
界面 #7A7A82   碰撞 #6A6A70   其他 #8E8E96
```

游戏色：泰拉科技 `#3E9B4F` · 战争机器人 `#C07A1E` · 重装上阵 `#8A5BD6`。

**对比度**：主文字对面板 ≥ 15:1，次要文字 ≥ 6:1，标签 ≥ 3.4:1，均满足 WCAG AA；
`--text-3` 不用于正文，只用于标签、单位、占位。

## 二、版面

```
48px 符号轨道 │ 44px 顶栏 │ 32px 排序条 │ 内容区（虚拟滚动） │ 24px 状态条
                                                          └ 392px 停靠详情（按需）
```

- 左轨道是**唯一允许纯符号**的区域（图标 18px，tooltip 补语义）
- 顶栏与排序条一律「图标 + 中文」，不做无字控件
- 停靠详情**推挤**布局而非覆盖，比较是资产库的主任务

### 居中查看器（双击卡片 / `Enter`）

信息**合计占半屏**（两侧各 25%），中间 50% 留给模型：

```
┌──────────────────── 44px 标题条：名称 · 分类 · 面数        ⟵ ⟶ ★ ✕ ────────────────┐
│ ┌─ 左信息板 25% ─┐ ┌────────── 中间 50% ──────────┐ ┌─ 右信息板 25% ─┐            │
│ │ 分类            │ │ ┌── 贴图排（顶）──────────┐ │ │ 几何            │            │
│ │ 标识            │ │ │ 原始材质 [t1][t2]… │平铺│亮度│ │ │ 标记            │            │
│ │ 贴图（角色+清单）│ │ └────────────────────────┘ │ │ 操作            │            │
│ └────────────────┘ │        [ 3D 视口 ]           │ └────────────────┘            │
│   ╲ 外缘退远        │  HUD 左下        统计 右下     │        外缘退远 ╱             │
└───────────────────────────────────────────────────────────────────────────────┘
```

**两侧斜切**：以**内缘**为转轴做透视旋转，外缘退远、内缘贴着视口边缘 ——
视觉上两板向内「包」住模型，内缘正对 3D 视口。

```css
.pane-l .pane-in{transform-origin:100% 50%;transform:perspective(1900px) rotateY(-7deg)}
.pane-r .pane-in{transform-origin:0% 50%;transform:perspective(1900px) rotateY(7deg)}
```

- 转轴压在内缘，旋转后内缘投影位置不动，只有外缘退远 ⇒ 斜切读起来是「朝向模型」
- 缩放窗口到 1280px 以下降到 ±5°，1024px 以下**取消斜切**（窄屏上透视只会浪费横向空间）
- 面板内缘加一道内阴影 `inset ±16px 0 22px -20px`，让斜切有厚度感
- 旋转在 `.pane-in` 上、滚动在 `.pane` 上 ⇒ 滚动条保持轴向，不跟着歪

**贴图排（中心上方）**：模型自带贴图横向排开，**点缩略图即覆盖到模型上**。

| 控件 | 行为 |
|---|---|
| `原始材质` | 还原为默认灰模（撤掉覆盖） |
| 贴图缩略图 ×N | 点击即替换材质贴图，选中项打蓝框 + 右上角点 |
| `平铺 ×1/×2/×4` | 设 `RepeatWrapping` 与 `repeat.set(n,n)` |
| 亮度滑杆 0.3–1.6 | 乘在材质基色上，用于看清暗部细节 |

打开时默认挂上第一张贴图，随时可点别的覆盖或切回原始材质。

**视图开关不重置视角**：实体 / 线框 / 贴图 / 网格 / 自动旋转 / 重置视角
只改材质与网格辅助线，**不重新加载 OBJ、不动相机**（同一模型走增量重绘路径）。


## 三、信息层级（卡片）

```
┌──────────────────────┐
│      缩略图           │  ← 16:11，object-fit: contain，透明底渲染图
│              [⧉]     │  ← 重复副本角标（右上，warn 色）
├──────────────────────┤
│ 名称                  │  12.5px / 600
│ ● 类型 · 分组          │  11px / 点 6px
│ 顶点 20.3k  面数 40.4k│  11px，label --text-3 + 值等宽（--mono）
│ 贴图 6      大小 4.0 MB│
│ ─────────────────────│
│ ● 游戏名              │  10.5px / --text-3
└──────────────────────┘
```

指标只留**四项跨游戏可比的量**：顶点 / 面数 / 贴图 / 大小。
尺寸与包围盒单位不一致（三游戏差 30 倍），只在详情面板作为原始值展示，**不进卡片、不做排序**。

层级递进：卡片给四项 → 悬停给完整 title → 停靠面板给全字段 → 居中查看器给 3D。

## 四、组件

| 组件 | 规格 |
|---|---|
| 按钮 | 高 28px，圆角 5px，1px `--line` 描边，hover 换 `--panel-2` |
| 分段控件 | 外框 1px，内项无圆角，选中 `--accent-soft` + `--accent` 文字 |
| 输入框 | 高 28px，focus 时边框转 `--accent` 且底色转 `--panel` |
| 卡片 | 圆角 7px，hover 只换描边色，**不做位移与缩放** |
| 列表行 | 高 34px，网格列宽恒定，选中 `--accent-soft` 底 + `--accent` 描边 |
| 标签 chip | 高 20px，`--panel-2` 底 + 6px 色点，不整块着色 |
| 圆角 | 全局 7px（小元素 4-5px），不用 14px+ 大圆角 |
| 动效 | 只做 100-180ms 的底色/描边过渡；无入场动画、无 blur 动画 |
| 滚动条 | 11px，thumb `--text-3`，3px 透明边框内缩 |

## 五、键盘与无障碍

- `Ctrl K` 搜索 · `Ctrl 1/2` 切视图 · `←→` 在停靠/查看器内连续翻 · `Esc` 逐层关闭 · `Enter` 开查看器
- 所有纯符号按钮带 `title`（同时作为 tooltip 与无障碍名）
- 焦点可见：`:focus-visible` 统一 2px `--accent` 描边
- 尊重系统深浅色偏好由手动切换承担（本工具是长时间浏览器场景，不跟随系统以免突然闪白）

## 六、缩略图策略

**贴图 ≠ 模型**：贴图与模型是多对一，31,611 个模型只对应 2,942 张不同贴图，
最夸张一张被 502 个模型共用。所以缩略图改为 `build_thumbs.py` 逐个 OBJ 离线渲染：

- 正交等轴测 + Lambert + z-buffer，512 渲染 → 256 输出，透明底 WebP，约 5 KB/张
- **按类型上色**，缩略图自带分类语义，同时与卡片上的类型点呼应
- 渲染失败或空模型 → 回退为该类型的符号，不出破图

## 七、明确不做

背景渐变光晕、毛玻璃 `backdrop-filter`、卡片悬浮位移/缩放、彩色药丸整块着色、
大圆角、Emoji 当图标、纯符号表达语义、跨游戏的体积排序。

斜切是唯一的例外：它承载「信息板在模型两侧、朝向模型」的结构语义，不是为了好看；
窄屏一律取消（见 §二）。
