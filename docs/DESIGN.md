# 设计规范 · 资产库界面

现行规范。原则：**做成一台干练的工具，不做展示页**。所有决定都服务于
「在三万条资产里快速找到、并正确判断一个模型」。

## 一、色彩

一套灰阶 + **单一强调色**。颜色**只出现在「点」上**（6px 类型点 / 游戏点 / 状态点），
不铺面板、不做渐变、不做毛玻璃。

| 令牌 | 浅色 | 深色 | 用途 |
|---|---|---|---|
| `--bg` | `#EFEFF1` | `#151517` | 应用底 |
| `--panel` | `#FFFFFF` | `#1D1D20` | 面板 / 卡片 |
| `--panel-2` | `#F7F7F8` | `#232327` | 次级面（表头 / 缩略图底 / 代码块） |
| `--line` | `#E2E2E5` | `#323238` | 结构分隔线 |
| `--line-2` | `#EDEDEF` | `#292930` | 组内分隔线 |

| `--text-2` | `#5F5F66` | `#9C9CA5` | 次要文字 |

## 二、版面

```
48px 符号轨道 │ 52px 头部（品牌·搜索·视图·密度·排序·副本·统计·主题） │ 内容区 │ 24px 状态条
                                                              ↑ 筛选条（仅在有筛选时出现）
```

- 左轨道是**唯一允许纯符号**的区域（图标 18px，tooltip 补语义）
- 头部与排序菜单一律「图标 + 中文」，不做无字控件
- **没有右侧停靠栏**：详情一律走居中的总览面板（见下），列表区不再被挤窄
- 原来的「44 顶栏 + 32 排序条」两条堆叠已合并为**一条 52px 头部**，
  排序收进菜单，省下的 24px 纵向空间全给内容
- **筛选条**只在确有筛选时出现，把「现在被什么筛着」摆在明面上，每项可一键摘掉

### 详情总览面板（点卡片即开）

**占屏 92% × 92%**，四周留 4% 露出底下的网格；面板水平垂直都居中（实测左 66 / 右 66 / 上 34 / 下 34）。

```
┌───────────────── 48px 顶条：名称 · 分类 · 分组 · 面数      ⟵ ⟶ ★ │ 操作组 ✕ ─────────┐
│ ┌─ 左信息板 22% ─┐ ┌─────────── 中间 56% ───────────┐ ┌─ 右信息板 22% ─┐          │
│ │ 分类            │ │ ┌── 贴图排（中心上方）────────┐ │ │ 几何（含最长边/面顶点比）│          │
│ │ 标识（7 字段）   │ │ │ 原始材质 [t1][t2]… │平铺│亮度│ │ │ 关联（同游戏/类型/分组 │          │
│ │ 贴图（角色+清单）│ │ └───────────────────────────┘ │ │       /同名族/共用贴图）│          │
│ └────────────────┘ │        【 3D 模型 可拖动 】      │ │ 标记 / 索引             │          │
│   ╲ 外缘退远        │  HUD 左下        统计 右下       │ └────────────────┘          │
└─────────────── 遮罩：底下的网格可见但压暗 44% ───────────────────────────────────────┘
```

**两侧斜切**：以**内缘**为转轴做透视旋转，外缘退远、内缘钉在面板边缘 ——
视觉上两板向内「包」住模型，是 3D 形态而不是平面 UI。

```css
.pane-l .pane-in{transform-origin:100% 50%;transform:perspective(1500px) rotateY(-9deg) rotateX(1.2deg)}
.pane-r .pane-in{transform-origin:0% 50%;transform:perspective(1500px) rotateY(9deg)  rotateX(1.2deg)}
```

- 转轴压在内缘，旋转后内缘投影位置不动，只有外缘退远 ⇒ 斜切读起来是「朝向模型」
- 加 1.2° 的 `rotateX` 让两块板略略俯向观者，避免纯 rotateY 的"翻书"感
- 缩放窗口到 1280px 以下降到 ±5°，1024px 以下**取消斜切**（窄屏上透视只会浪费横向空间）
- 面板内缘加一道内阴影 `inset ±18px 0 26px -22px`，让斜切有厚度感
- 旋转在 `.pane-in` 上、滚动在 `.pane` 上 ⇒ 滚动条保持轴向，不跟着歪

**贴图排（中心上方）**：模型自带贴图横向排开，**点缩略图即覆盖到模型上**。

| 控件 | 行为 |
|---|---|
| `原始材质` | 还原为默认灰模（撤掉覆盖） |
| 贴图缩略图 ×N | 点击即替换材质贴图，选中项打蓝框 + 右上角点 |
| `平铺 ×1/×2/×4` | 设 `RepeatWrapping` 与 `repeat.set(n,n)` |
| 亮度滑杆 0.3–1.6 | 乘在材质基色上，用于看清暗部细节 |

打开时默认挂上第一张贴图，随时可点别的覆盖或切回原始材质。

**视图开关不重置视角**：实体 / 线框 / 贴图 / 网格 / 自动旋转 / 重置视角
只改材质与网格辅助线，**不重新加载 OBJ、不动相机**（同一模型走增量重绘路径）。

#### 取景：按包围盒 8 角精确解，并让出 UI 占住的边带

两条硬约束，缺一条就会「模型被切掉」：

1. **UI 不许压在画布上**。贴图排一律走文档流（`flex:0 0 auto; margin:10px 12px 0`），
   画布独占剩下的整块 —— 绝对定位的浮条会盖住模型顶部，这不是观感问题而是功能性遮挡。
2. **相机距离要解出来，不能拍脑袋**。曾经的 `.position = c + (r*1.45, r*0.95, r*1.45)`
   对单位立方体给出张角 `asin(0.866/2.23)=22.8°`，而竖直半视角只有 20° —— 竖向上模型
   天生被切一截。现在的算法：

```
f  = (画布高/2) / tan(fov/2)            # 焦距（像素）
d >= a + |v|·画布高/(安全区高·tanV)      # 每个角都要落进安全区（竖直）
d >= a + |h|·画布高/(安全区宽·tanV)      # 同上（水平）
取 8 角的约束最大值 ×1.04 余量
再把投影内容的垂直中心对齐到安全区中心
```

- `a / h / v` = 该角在相机坐标架下的纵深 / 横向 / 竖向分量（坐标架与 three 的 `lookAt` 同约定）
- **安全区** = 画布减去 HUD（左下）与提示条（右上）占住的边带，由 `safeBand()` 实测得出
- 屏幕 y **向下为正**，所以投影取 `-f·v/depth`；符号写反会让补正翻倍、把模型推出安全区（踩过）
- 画布尺寸一变（窗口缩放 / 贴图排显隐）由 `ResizeObserver` 触发重新取景

实测（185 × 24 × 185 单位的地形板）：投影 `x 54~798 / y 143~498`，
安全区 `y 34~628`，**完整落在安全区内、远角超界 0**，占画布 87% 宽。


## 三、信息层级

分三层递进，**每一层都能独立回答一个问题**：

| 层级 | 回答 | 内容 |
|---|---|---|
| 卡片 | 一眼扫过 | 缩略图 / 名称 / ● 类型·分组 / 顶点·面数·贴图·大小 / ● 游戏 |
| 列表行 | 逐行比较 | 同上的横向展开，表头可点排序 |
| 总览面板 | 定案前核对 | 分类 3 值 · 标识 7 字段 · 贴图角色与清单 · 几何 8 项 · 关联 5 项 · 标记 · 索引 3 项 |

**关联**这一段是「超级详细」里最有用的一块：同游戏 / 同类型 / 同分组 / 同名族 /
共用首张贴图各有多少个 —— 决定能不能复用、会不会挑错版本。

## 五、键盘与无障碍

- `Ctrl K` 搜索 · `Ctrl 1/2` 切视图 · `←→` 在总览面板内连续翻模型 · `Esc` 逐层关闭 · 点卡片即开面板
- 所有纯符号按钮带 `title`（同时作为 tooltip 与无障碍名）
- 焦点可见：`:focus-visible` 统一 2px `--accent` 描边
- 尊重系统深浅色偏好由手动切换承担（本工具是长时间浏览器场景，不跟随系统以免突然闪白）

## 六、缩略图策略

**贴图 ≠ 模型**：贴图与模型是多对一，31,611 个模型只对应 2,942 张不同贴图，
最夸张一张被 502 个模型共用。所以缩略图改为 `build_thumbs.py` 逐个 OBJ 离线渲染：

- 正交等轴测 + Lambert + z-buffer，512 渲染 → 256 输出，透明底 WebP，约 5 KB/张
- **按类型上色**，缩略图自带分类语义，同时与卡片上的类型点呼应
- 渲染失败或空模型 → 回退为该类型的符号，不出破图

## 七、明确不做

背景渐变光晕、毛玻璃 `backdrop-filter`、卡片悬浮位移/缩放、彩色药丸整块着色、
大圆角、Emoji 当图标、纯符号表达语义、跨游戏的体积排序。

斜切是唯一的例外：它承载「信息板在模型两侧、向内朝向模型」的结构语义，不是为了好看；
窄屏一律取消（见 §二）。

同样明确不做的还有：**右侧停靠详情栏**。详情只在正中的总览面板里出现，
主列表永远拿满宽度。
